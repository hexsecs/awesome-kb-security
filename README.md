# Security (Awesome KB)

**Rendered site: https://hexsecs.github.io/awesome-kb-security/** — also
composed into the network site at
https://hexsecs.github.io/awesome-kb/ once registered imports build.

A living knowledge base for security — tools, research, and practice
across offensive and defensive security — in the
[OpenShelf](https://github.com/OpenNorms/openshelf) format: a canon awesome
list feeds a wiki of researched pages, maintained jointly by bots and
humans. Part of the [Awesome KB](https://github.com/hexsecs/awesome-kb)
network.

**Status: scaffold (2026-11-01).** Structure, manifest, registry
registration, and standalone rendering are in place. The canon source
list has not been designated yet, so the KB holds no entity pages; once
the owner designates the list, ingest begins and pages accumulate.
